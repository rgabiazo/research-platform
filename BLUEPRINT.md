# Blueprint

This file remains only to preserve historical references to `BLUEPRINT.md`.
It is not the authority for current architecture, present support, future
commitments, or release requirements.

Use the public documents with those specific roles:

- [ARCHITECTURE.md](ARCHITECTURE.md) describes the current system and its
  structural boundaries.
- [ROADMAP.md](ROADMAP.md) describes possible future direction without making
  a calendar or release commitment.
- [docs/capabilities.md](docs/capabilities.md) records current support,
  evidence, prerequisites, and limitations.
- [accepted decision records](docs/decisions/README.md) contain reviewed
  technical and governance decisions.

Earlier blueprint material mixed completed work, design ideas, and
implementation planning. Keeping this path preserves historical context
without giving that material current authority. New public documentation
should use the documents above instead.
